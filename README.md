## 命名规范

- 统一前缀：`奶蛙-`；官方旧名「奶龙」字样全部替换为「奶蛙」。
- 系列内按语义/序号命名：`奶蛙-弯腰大笑.png`、`奶蛙-表情-01.jpeg`、`奶蛙-艺术-01.png`。
- 视频帧图保留原秒数标记：`奶蛙-帧图-最伟大的奶蛙-05s.png`。
